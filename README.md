# 妊娠期糖尿病（GDM）预测 —— 机器学习初学者实战实例

> 一个面向机器学习初学者的完整实例，带你从零完成数据加载、模型训练到结果评估的全流程。

---

## 📖 项目简介

本项目是一个面向机器学习初学者的完整实战实例。项目基于若干临床指标，并结合 NPAR（中性粒细胞/淋巴细胞比值相关指标）来预测妊娠期糖尿病（GDM），并对比多种机器学习算法的预测性能。

通过本项目，你可以从零走完 **数据加载 → 数据预处理 → 模型训练 → 结果评估** 的完整机器学习流程。

---

## 📂 项目结构

| 文件 | 说明 |
| --- | --- |
| `Machine_Learning.ipynb` | 机器学习的完整代码（Notebook 形式，含注释与流程说明） |

| `prediction_NHANES_test.xlsx` | NHANES 测试集 |
