# 这是一个给初学者学习的机器学习实例

> 一个面向机器学习初学者的完整实例，带你从零完成数据加载、模型训练到结果评估的全流程。

## 📖 项目简介

本项目使用经典的**鸢尾花数据集（Iris Dataset）**，通过简单的分类算法演示机器学习的完整流程。
即使你没有任何机器学习基础，也可以跟着步骤一步步运行并理解每一行代码。

## 🎯 学习目标

完成本实例后，你将能够：

- 理解机器学习的基本流程：数据 → 模型 → 训练 → 评估
- 使用 `scikit-learn` 加载数据集并划分训练/测试集
- 训练一个简单的分类模型（如 KNN、决策树）
- 评估模型效果并理解准确率指标
